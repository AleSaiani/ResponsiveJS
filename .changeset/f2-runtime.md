New package (F2): the authoring runtime. Reactive `value = f(width)` with a zero-dependency TC39-shaped signal engine, `fluid()` (linear/eased/exponential curves, per-breakpoint arrays, OKLab color interpolation, structural string interpolation), `when`/`whenInRange`/`breakpoint.*` conditionals, CSS-first compilation (Utopia `clamp()`, `@media` blocks, `cqi` for containers), container-aware values via a shared ResizeObserver, `grid`/`space`/`typography` helpers, lazy/memo/batch/debug utilities, tagged-template and utility-string grammars.
