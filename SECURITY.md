# Security Policy

## Supported versions

Only the latest published version of each `@responsivejs/*` package receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Instead, report privately via
[GitHub Security Advisories](https://github.com/AleSaiani/ResponsiveJS/security/advisories/new).

You can expect an acknowledgement within a few days. Please include a minimal reproduction and the
affected package/version.
